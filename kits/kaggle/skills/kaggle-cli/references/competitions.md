# Kaggle Competitions Reference

## Commands
- `kaggle competitions list`: List available competitions.
- `kaggle competitions files -c <id>`: List files in competition.
- `kaggle competitions download -c <id>`: Download all files.
- `kaggle competitions submit -c <id> -f <file> -m "<message>"`: Submit predictions.
- `kaggle competitions submissions -c <id>`: View past submissions.
- `kaggle competitions leaderboard -c <id> --show`: View current standings.
