# Kaggle Kernels Reference

## Commands
- `kaggle kernels list -s <search>`: Search notebook kernels.
- `kaggle kernels init -p <dir>`: Initialize kernel-metadata.json template.
- `kaggle kernels push -p <dir>`: Push and execute notebook kernel remotely.
- `kaggle kernels pull <slug> -p <dir> -m`: Pull notebook file and metadata.
- `kaggle kernels status <slug>`: Check execution status of kernel.
- `kaggle kernels output <slug> -p <dir>`: Download kernel output files.
