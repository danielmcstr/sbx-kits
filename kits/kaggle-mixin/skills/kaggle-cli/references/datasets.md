# Kaggle Datasets Reference

## Commands
- `kaggle datasets list -s <search>`: Search for datasets.
- `kaggle datasets download -d <dataset> --unzip`: Download and extract dataset.
- `kaggle datasets create -p <dir>`: Create new dataset from directory with dataset-metadata.json.
- `kaggle datasets version -p <dir> -m "<msg>"`: Create a new version of existing dataset.
- `kaggle datasets status <dataset>`: Check creation/update status.
